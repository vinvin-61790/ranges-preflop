# Ranges Preflop GTO – compiler l'APK

1. Créez un dépôt GitHub (gratuit) et envoyez-y tout le contenu de ce dossier
   (y compris le dossier caché .github).
2. Onglet "Actions" > "Build APK" > attendez ~5 min (ou "Run workflow").
3. Ouvrez l'exécution terminée > "Artifacts" > téléchargez ranges-preflop-gto-apk.
4. Dézippez, copiez app-debug.apk sur le téléphone et installez-le
   (autoriser les sources inconnues).
